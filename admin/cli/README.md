# CLI Script to delete tenants by [eLeDia](https://eledia.de/)
## Description
This script by [eLeDia](https://eledia.de/) deletes tenants with all associated  
- course categories
- courses
- users

## Usage
Place the script file into the `admin/cli` directory of your moodle installation.
`sudo -u www-data /usr/bin/php admin/cli/eledia_delete_workplacetenant.php --help` gives you further information about usage.
